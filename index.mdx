Scramjet is an experimental, high-performance web proxy that runs entirely in the browser. By combining service worker interception, a Rust/WebAssembly rewriter, and a pluggable transport layer, Scramjet lets you proxy arbitrary web content — including complex sites like Google, YouTube, and Discord — without any server-side rendering.

## What Scramjet Can Do

Scramjet proxies full web applications — not just static pages. Its Rust/WASM rewriter rewrites JavaScript, HTML, CSS, and WebAssembly on-the-fly, and a pluggable transport layer tunnels requests over WebSocket via the [Wisp protocol](https://github.com/MercuryWorkshop/wisp-protocol).

<CardGroup cols={3}>
  <Card title="JS Rewriting" icon="js">
    Rewrites JavaScript at the AST level to intercept globals like `location`, `document`, `fetch`, and `eval`.
  </Card>
  <Card title="HTML & CSS" icon="html5">
    Rewrites HTML attributes and CSS `url()` values so all sub-resources load through the proxy.
  </Card>
  <Card title="WebSocket Proxying" icon="wifi">
    Proxies WebSocket connections via the Wisp protocol, with Epoxy and libcurl transport options.
  </Card>
  <Card title="Cookie Sync" icon="cookie">
    Synchronizes cookies across all frames and the service worker with IndexedDB persistence.
  </Card>
  <Card title="Plugin System" icon="puzzle-piece">
    Extend Scramjet with ordered hooks on fetch, init, and error lifecycle events.
  </Card>
  <Card title="HTTP Cache" icon="database">
    RFC 9111-compliant HTTP caching plugin that caches upstream responses in the browser Cache API.
  </Card>
</CardGroup>

## Get Started in Minutes

<Steps>
  <Step title="Scaffold a new proxy app">
    Use the `create-proxy-app` CLI to generate a working project in seconds.

    ```bash
    npx create-proxy-app my-proxy
    cd my-proxy
    npm install
    ```
  </Step>
  <Step title="Start the development server">
    ```bash
    npm run dev
    ```
    Your proxy will be running at `http://localhost:3030`.
  </Step>
  <Step title="Navigate to a site">
    Open the demo page and enter any URL to browse it through Scramjet.
  </Step>
  <Step title="Customize and extend">
    Add plugins, swap transports, configure codecs, and hook into the fetch lifecycle to tailor the proxy to your needs.
  </Step>
</Steps>

## Supported Sites

Scramjet supports many popular websites out of the box, including Google, YouTube, Instagram, ChatGPT, Reddit, Twitter/X, Discord, Spotify, GeForce NOW, and more.

<Note>
  Scramjet is experimental software under active development. The API surface may change between releases. Pin your dependencies to a specific major version to avoid breaking changes.
</Note>
